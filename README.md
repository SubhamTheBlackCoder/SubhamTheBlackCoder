> Distributed, event-driven system for intelligent resume processing at scale

| Metric | Result |
|--------|--------|
| 🎯 Skill matching accuracy | **89%** |
| ⚡ Latency reduction | **60%** |
| 🏗️ Architecture | Distributed, event-driven |
| ☁️ Infrastructure | AWS + Serverless |

**What makes it different:**
- Asynchronous processing pipeline for high-throughput resume ingestion
- AI-powered semantic skill extraction and matching
- Fault-tolerant event-driven architecture with dead-letter queues
- Built to scale horizontally without re-architecture

**Stack:** `Node.js` `Spring Boot` `AWS Lambda` `DynamoDB` `SQS` `RabbitMQ` `Redis` `PostgreSQL`
